# retro-lab

Hobby experiments from 2013–2019: retro computers, bare-metal x86, a hand-made 3D engine and microcontrollers.
Each folder was a separate repository; its full commit history is kept here.

| Folder | What it is | Previously |
|---|---|---|
| [c64](c64) | ANSI C (cc65), assembly (DASM) and BASIC 2.0 on the Commodore 64 | [michalasobczak/c64](https://github.com/michalasobczak/c64) |
| [x86-bootloader](x86-bootloader) | 2D/3D graphics in NASM x86 assembly, inside a 512-byte boot sector | [michalasobczak/x86-bootloader](https://github.com/michalasobczak/x86-bootloader) |
| [js3d-engine](js3d-engine) | JavaScript 3D engine (2013): textured faces, occlusion culling, lighting, collisions | [michalasobczak/js3d-engine](https://github.com/michalasobczak/js3d-engine) (formerly `generic`) |
| [esp8266](esp8266) | Lua on NodeMCU firmware for the ESP8266 | [michalasobczak/esp8266](https://github.com/michalasobczak/esp8266) |

The old repositories are archived (read-only) and point here.
